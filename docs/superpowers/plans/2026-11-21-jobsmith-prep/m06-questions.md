insert into prep_mark (user_id, scope, opportunity_id, question_key, level, marked_at, drill_count, last_drilled_at)
values (:userId, :scope, :opportunityId, :questionKey, :level, :markedAt, case when :drilled then 1 else 0 end, case when :drilled then :markedAt end)

- [ ] **Step 3: Implement `parseQuestionBank` in `lib/prep/parse.ts`**

One pass over lines (normalize CRLF first), a small state machine: `section`, `current question`, `current block`, `ignoring` (after `####`). Rules:

```text
question line   ^### (\d+)\. (.*)$   starts a question; any other "### " line ends the current question and is section text
"## " line      ends the question, sets section (trimmed heading text); "# " and blank lines outside a block do nothing
"#### " line    ends the current block and sets ignoring = true until the next label line or ### / ## heading
"---" line      skipped
bold label      ^\*\*([^*]+?)(:?)\*\*(:?)\s*(.*)$   label = group 1 without a trailing colon; rest of the line starts the text
italic label    ^\*([^*]+?):\*\s*(.*)$              classified with style "italic"
include line    ^\{\{include\s+(\S+)\s+(\d+)(?:\s+(\S+))?\}\}\s*$   inside a question
```

Heading text: cut at the first `WARNING_MARKER` (remove it and everything after it only when the marker follows the last closing quote; when the marker sits inside an open quote, remove just the marker and warn `marker_inside_quote`), then cut at the first ` (`, then strip surrounding straight or curly quotes and collapse whitespace. `unfilled` is true when the marker is present anywhere on the heading line. Lines after a label continue its text (joined with `\n`, trimmed) until the next label, heading or `---`. Lines inside a question before any label form one note block with label `""`. A spoken block whose trimmed text is empty is dropped. `hasAnswer` is true when at least one spoken block remains. Each warning carries the 1-based `line` and the question number (or `null` above the first question). An include resolved by `options.resolveInclude(file, number)` appends the returned blocks (spoken only) at that position; unresolved appends a note block (label `""`) and increments `unresolvedIncludes`.
